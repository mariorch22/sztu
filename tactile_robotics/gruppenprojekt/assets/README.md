# PAXINI DexH13 left hand

Copied from `../../labs/lab4/slides/assets/paxini_left_hand.xml` and the
associated `lab4/replay_assets/meshes/` files. Only mesh file paths in the XML
were changed to use the local `meshes/` directory. Mesh contents are unchanged.
The source metadata is preserved in `paxini_hand_source.json`.

This is the presentation hand model with 16 movable joints and no actuators.
`replay.py` sets recorded joint positions directly for kinematic playback.
The colors, including the cyan index fingertip, come from the presentation.

The source lab attributes the robot assets to `kiramint/Dexman_Lerobot` and
`kiramint/Dexman_ROS2_SDK`. Original third-party ownership and terms apply;
copying these assets does not grant a new license.
